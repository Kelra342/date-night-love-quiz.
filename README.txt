A LITTLE LOVE QUIZ — DATE NIGHT WEBSITE

FILES
- index.html: page structure
- css/style.css: design and responsive layout
- js/script.js: 10-question love quiz and interactions
- assets/heart-bounce.gif and assets/heart-party.gif: local animated GIFs

HOW TO OPEN ON A MAC
1. Extract the ZIP file.
2. Open the Date_Night_Love_Quiz folder.
3. Double-click index.html and choose Safari or Chrome if asked.
4. Internet is optional for the core game. Google Fonts are loaded online; local fallback fonts are included.

HOW TO PLAY
- Click “Okay, let's play”.
- Answer 10 different love questions.
- The “No” button is intentionally playful and dodges the pointer/touch.
- Click “Yes” to continue.
- On the final question, the love certificate appears.

NOTES
- The website runs locally in your browser and does not send answers to a server.
- It uses locally included GIF assets. It does not require VS Code.
- If you publish it online, keep index.html, css/, js/, and assets/ together.
